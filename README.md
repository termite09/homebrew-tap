# termite09/tap

Homebrew casks for [termite09](https://github.com/termite09)'s apps.

```bash
brew install --cask --no-quarantine termite09/tap/bubble-for-messenger
```

`--no-quarantine` because Bubble for Messenger is not signed with an Apple developer
certificate; without it, macOS asks you to right-click → Open on the first launch.
